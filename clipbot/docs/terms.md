# ClipBot — Conditions d'utilisation

ClipBot est un outil personnel, installé sur l'ordinateur de son propriétaire, qui monte des clips vidéo et les envoie sur le compte TikTok de ce même propriétaire.

- L'outil n'est pas proposé au public : seul son propriétaire l'utilise, avec son propre compte TikTok.
- Les vidéos sont envoyées en visibilité privée ; le propriétaire décide lui-même de les rendre publiques.
- Chaque clip crédite le créateur d'origine. Un clip est retiré sur simple demande de ce créateur.
- L'outil est fourni tel quel, sans garantie.

Contact : via les « Issues » de ce dépôt GitHub.
