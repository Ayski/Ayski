# ClipBot — Politique de confidentialité

ClipBot fonctionne entièrement sur l'ordinateur de son propriétaire.

- **Données TikTok utilisées** : nom et avatar du compte connecté, statistiques du compte, liste et statistiques de ses vidéos. Elles servent uniquement à afficher le tableau de bord et à publier les clips.
- **Stockage** : ces données et les jetons de connexion restent dans une base locale sur l'ordinateur du propriétaire. Rien n'est envoyé à un serveur tiers, vendu ou partagé.
- **Suppression** : déconnecter le compte dans l'application efface ses jetons ; supprimer le dossier de données efface tout.

Contact : via les « Issues » de ce dépôt GitHub.
